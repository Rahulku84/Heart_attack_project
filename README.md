# Heart Attack Data Analysis Using Python

## 📌 Project Overview

This project explores heart attack history using health survey data and Python. It focuses on data cleaning, exploratory data analysis (EDA), statistical summaries, and interactive visualizations to understand how reported heart attack history varies across different demographic and health-related groups.

## 🎯 Objectives

- Explore and understand the dataset structure.
- Identify missing values, duplicate records, and unusual values.
- Clean and prepare data for analysis.
- Analyze heart attack history across age groups and sex.
- Explore patterns related to smoking status, physical activity, BMI, sleep duration, and general health.
- Compare heart attack history with diabetes and other reported health conditions.
- Generate interactive charts and export analysis tables and reports.

## 🛠️ Technologies Used

- **Python** — Data analysis and processing
- **Pandas** — Data cleaning and manipulation
- **NumPy** — Numerical operations
- **Plotly Express** — Interactive data visualization
- **Google Colab** — Notebook execution

## 📊 Key Analysis Areas

- Dataset overview and descriptive statistics
- Missing-value analysis
- Duplicate and data-quality checks
- Numerical distributions and potential outliers
- Heart attack response distribution
- Analysis by age group and sex
- Smoking status and physical activity
- BMI ranges and sleep duration
- General health and diabetes categories
- Other reported health conditions
- Physical and mental health days
- Comparisons across age and sex groups

## 📈 Outputs

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open `heart_problem.ipynb` in Google Colab or Jupyter Notebook.
3. Upload the dataset or update the dataset path in the notebook.
4. Install the required libraries if they are not already available:

```bash
pip install pandas numpy plotly
```

5. Run the notebook cells in order.
6. Review the charts, analysis tables, and generated reports.

**Google Colab users:** The notebook currently uses Google Drive mounting and a Drive file path. Update this path to match your dataset location before running it.
